# Sistema Bancário

Este projeto é uma implementação simples de um sistema bancário em Python, desenvolvida como parte do curso Fundamentos de Linguagem Python - Do Básico a Aplicações de IA da Data Science Academy.

## Funcionalidades

- Cadastro de clientes
- Cadastro de contas bancárias
- Realização de movimentações
- Exibição de clientes e contas

## Estrutura do projeto

- main.py: ponto principal da aplicação
- entidades/cliente.py: definição da classe Cliente
- entidades/conta.py: definição da classe Conta

## Como executar

Execute o arquivo principal com:

```bash
python main.py
```

## Objetivo

Praticar conceitos básicos de programação orientada a objetos em Python, como classes, objetos, atributos e métodos, além de controle de fluxo e interação com o usuário.
